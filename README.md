🔐 Password Strength Checker

📌 About the Project

Password Strength Checker is a web application that checks the strength of a password and helps users understand whether their password is weak, medium, or strong.

✨ Features

- Checks password strength.
- Provides feedback on password security.
- Simple and user-friendly interface.
- Built using Python, HTML, CSS, and JavaScript.

🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

📂 Project Structure

password-strength-checker/

├── requirements.txt
├── templates/
│   └── index.html
├── static/
│   ├── style.css
│   └── main.js

🚀 How to Run the Project

1. Clone this repository.

2. Install the required dependencies:
   
   "pip install -r requirements.txt"

3. Run the application:
   
   "python app.py"

4. Open the local URL shown in the terminal in your browser.

🎯 Project Objective

The objective of this project is to understand password security concepts and practise web development using Python and frontend technologies.
